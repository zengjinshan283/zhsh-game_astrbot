## 第一部分：支线任务设计（12个）

### 设计原则
- 覆盖10-100级区间
- 每个任务独立完整，有明确剧情
- 奖励与等级匹配，递增合理
- 任务类型多样：杀怪/收集/对话/护送/探索

#### 支线1：威尼斯渔夫的困扰

**接取NPC**：马可（Marco，威尼斯酒馆）
**任务类型**：杀怪
**目标**：击败海上劫匪×3
**等级需求**：Lv10
**前置任务**：无

**任务描述**：
> *「老渔夫托尼诺的儿子出海打渔时被海盗抓走了，海盗就在威尼斯附近海域游荡。帮他找回他儿子的下落！」*

**NPC对话（接取）**：
```
马可：托尼诺是我多年的老友了，他儿子前几天出海遇到了海盗，至今没有消息。
     如果你有空的话，去威尼斯近海找找那些海盗，教训他们一下！
     最好能找到他儿子的消息。
```

**NPC对话（完成）**：
```
马可：你找到了托尼诺儿子的遗物……他已经……
     我会转告托尼诺的。这点钱你拿着，感谢你为他做的一切。
     海上的危险比你想象的要大，年轻人，要小心。
```

**奖励**：EXP+300，铜币+500，小回复药×3

**后续**：无

#### 支线2：迷失的船员

**接取NPC**：码头管理员（威尼斯码头）
**任务类型**：收集
**目标**：收集海员信物×3（海上劫匪掉落）
**等级需求**：Lv15
**前置任务**：支线1完成

**任务描述**：
> *「一艘商船在风暴中失联，船员们可能还活着。找到他们的信物，确认他们的身份。」*

**NPC对话（接取）**：
```
码头管理员：昨天有艘商船在风暴中失联了，听说有几个船员游到了附近的小岛上。
             他们的家属都很担心。帮我收集一些他们的信物，比如船员牌或者护身符。
```

**NPC对话（完成）**：
```
码头管理员：这些确实是那艘船船员的信物……感谢你！
             虽然他们已经遇难了，但至少家属们可以得到一个确切的消息。
```

**奖励**：EXP+400，铜币+800，**海员长袍×1**（蓝装DEF+5）

**后续**：自动接取支线3

#### 支线3：亚历山大的炼金术士

**接取NPC**：法拉（Alexandria炼金术士）

**目标**：收集草药×5 + 翡翠石×2

**NPC对话（接取）**：
```
法拉：我正在研究一种能够抵御沙漠诅咒的护身符。
     我需要5份草药和2份翡翠石，你能帮我收集吗？
```

**NPC对话（完成）**：
```

     作为报酬，我给你调配了一瓶驱魔法阵——以后遇到诅咒类敌人会有用的。

```

**奖励**：EXP+500，铜币+1000，**驱魔法阵×2**（异常状态解除道具）
