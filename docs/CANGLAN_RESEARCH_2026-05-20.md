## 一、登录方式（技术细节）

Java Spring Boot 框架，登录接口只接受 `application/x-www-form-urlencoded`：

```
Step 1: GET  /yuanqi/player/login        → 建立 session
Step 2: POST /login (data={username, password, rememberMe})
Step 3: GET  /yuanqi/enterGame?serviceId=1&recent=true
        → 从返回 HTML 中提取 cmd=XXX
Step 4: GET  /yuanqi/game?cmd={main_cmd} → 游戏主页
```

游戏内所有页面均通过 `cmd` 参数访问，cmd 是动态 token，需从上级页面提取。

## 十、宠物系统

### 宠物状态
当前无宠物。宠物需要**孵化栏**孵化。

### 宠物机制
1. 宠物**自动成长**，消耗清洁值和饱食值
2. 任一项为0时停止成长，进入**休息状态**
3. 宠物**自动修炼技能**，同样消耗清洁/饱食
4. 休息状态不增加技能点

### 宠物技能（20+个）

**攻击型**：
- 嗜血：10%概率把攻击伤害转化为自身HP
- 噬魂：30%概率造成(等级×10)%攻击力的真实伤害，20%施加撕裂（8秒+20%受伤）
- 血刃：20%概率让对手无法反弹

**辅助型**：
- 净化：20%概率净化所有负面效果
- 利刃：本次战斗+10%攻击
- 卸刃/卸甲/卸佩：20%概率卸掉对方装备
- 威压：降低对手所有数值和特性10%
- 御敌：本次战斗+10%防御
- 怒吼：自身所有数值升高10%
- 无敌：20%概率3秒内免疫所有攻击
- 迷惑：20%概率让对方宠物退出战斗

**治疗型**：
- 疗伤：战斗完成后恢复10%体力
