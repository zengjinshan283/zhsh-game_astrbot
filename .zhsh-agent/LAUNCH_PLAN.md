# 纵横四海 - Agent 团队运营计划

## 最终目标
**可上线、玩家可玩的航海RPG游戏**

## 现状评估

### ✅ 核心系统就绪
- 登录/注册/角色创建
- 战斗系统（回合制+技能+装备耐久）
- 装备系统（词缀+强化+套装属性UI）
- 航海系统（购买船只+航线+海盗战+码头交互）
- 地图系统（城内移动+野外遇怪+城市内无怪物）
- 消耗品+debuff系统
- 签到/福利/每日活跃
- 竞技场/副本/宠物/公会框架
- 管理后台（15个路由全通）

### 🔴 上线前必须完成

| 优先级 | 事项 | 现状 |
|--------|------|------|
| P0 | **支线任务内容** | 247个多为占位符 |
| P0 | **新手引导完善** | 有框架，内容粗糙 |
| P0 | **游戏货币循环** | 打怪→买装备→强化→更强，闭环未验证 |
| P1 | **副本次数限制** | 可无限刷，破坏平衡 |
| P1 | **航海立即完成** | 等待时间长，挫败感 |
| P1 | **新手装备** | 1级无合适装备 |
| P2 | **特性天赋系统** | 完全无 |
| P2 | **宠物自动成长** | 宠物不升级 |

### 🔵 上线后持续运营
- 新地图/新怪物
- 活动系统
- 玩家反馈迭代

## Agent 团队分工

| Agent | 职责 |
|-------|------|
| Orchestrator | 需求优先级、任务分发、代码审核 |
| Backend Dev | 后端逻辑、数据库、API |
| Frontend Dev | Vue页面、UI优化 |
| QA | 接口测试、功能验证、找bug |

## 当前 sprint 目标
**完成 P0 + P1 项，使游戏可玩**

## 决策规则
- 表结构/架构变更 → 提确认
- 新功能涉及外部依赖 → 提确认
- 10分钟内无法完成 → 拆分
