# 纵横四海 - Agent 团队开发流程

## 项目信息

- **路径**: /home/ubuntu/work/zhsh-game_astrbot
- **分支**: future（所有开发都在此分支）
- **后端入口**: node server/src/app.js（端口 3000）
- **前端**: Vue3，dev 端口 5173
- **数据库**: MySQL 本机，root 无密码，库名 zhsh_game

## 团队角色

### 1. Orchestrator（主编）
- 优先级排序，持续发现需求
- 拆解任务分发给各 agent
- 审核代码，统一 commit

### 2. Backend Dev（后端开发）
- Node.js 路由开发
- MySQL 表结构变更
- API 逻辑实现

### 3. Frontend Dev（前端开发）
- Vue3 页面和组件
- UI/UX 改进

### 4. QA Tester（测试）
- 接口测试
- 功能验证

## 开发约定

- **先跑通后完善**：先实现核心逻辑
- **显著决策前确认**：涉及架构/表结构变更需确认
- **commit 粒度**：每个功能独立 commit，格式 `[功能名] 描述`
- **测试账号**: tester1 / test123456

## 任务优先级

### 高优先级
1. 支线任务内容填充
2. 副本次数限制
3. 航海立即完成道具

### 中优先级
4. 特性天赋系统
5. 宠物自动成长
6. 竞技场赛季/奖励

### 低优先级
7. 帮会攻城战
8. 领地生产系统
9. 藏宝图系统

## 决策规则

- 新功能涉及表结构变更 → 先提确认
- 涉及外部系统（如支付）→ 先提确认
- 单次 commit 代码量过大 → 拆分成多个
- 某任务 10 分钟内无法完成 → 拆解或先做最小可用版本
